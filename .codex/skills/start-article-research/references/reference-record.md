# Durable article reference record

Use this structure for `.drafts/blog/<id>/references.md`. Keep sections that already contain useful material and add subsections only when they improve retrieval.

```markdown
# 构思与研究记录｜文章标题

## 核心问题

- [作者判断] 用户实际提出的命题、担忧或直觉。
- [Agent 综合] 对若干讨论线索之间关系的压缩，但不冒充作者观点。

## 关键概念与边界

## 讨论中形成的新连接

## 证据与来源

### 证据主题

- 标签：[来源事实] / [待验证]
- 来源与 URL：
- 访问日期：YYYY-MM-DD
- 能支持的命题：
- 不能支持的命题：
- 局限、反例或竞争性解释：

## 可用案例、类比与理论工具

## 反例与竞争性解释

## 已作出的写作决定

- [保留] 已确认进入提纲的方向。
- [放弃] 讨论过但作者主动舍弃的方向，以及舍弃原因。

## 尚待确认
```

The record is not a bibliography and not a transcript. Every saved item should tell the drafting Skill how it may be used. Keep fact, inference, analogy, and normative recommendation distinct.
